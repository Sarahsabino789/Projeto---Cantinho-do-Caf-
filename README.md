# ☕ Cantinho do Café

Site institucional de uma cafeteria fictícia desenvolvido como projeto de aprendizado de HTML e CSS.

## 📄 Páginas

- **Home** — apresentação da cafeteria, diferenciais, localização, depoimentos
- **Cardápio** — categorias de café com rolagem horizontal
- **Seja um Investidor | Trabalhe Conosco** — formulários de contato e candidatura

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5 (dropdown mobile)
- Google Fonts
- Google Maps Embed
- Spotify Embed

## 📚 O que aprendi nesse projeto

- Estrutura semântica com header, main, section, article, footer, figure e address
- Flexbox: flex-direction, justify-content, align-items, flex-wrap, order, gap e flex: 1
- Posicionamento com position relative e absolute, z-index e transform
- Efeito leque com rotate, transform-origin e translateY
- Responsividade com @media queries para mobile e tablet
- Alternância de layout com a classe divisoria e divisoria-invertida
- Rolagem horizontal com overflow-x scroll
- Estilização de scrollbar com webkit-scrollbar
- Dropdown mobile integrado ao Bootstrap
- Boas práticas de organização de CSS com comentários por seção
- Identidade visual consistente com paleta de cores definida
